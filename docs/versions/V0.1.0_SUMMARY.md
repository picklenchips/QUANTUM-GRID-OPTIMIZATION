## Headline findings

- **No verified, unrebutted quantum-advantage claim exists for QUBO/combinatorial optimization**, mid-2024 through now. Same conclusion as this project's original notes — now backed by a much richer, skeptical literature. Recurring pattern: bold claim → classical rebuttal within weeks → vendor pushback.
- **On a real energy problem, D-Wave hybrid still loses to Gurobi/CPLEX** ([arXiv:2409.05542](https://arxiv.org/abs/2409.05542)). Most recent grid-specific benchmark (Jul 2026) found a hybrid UC method not beating uniform random sampling.
- **Direct upgrade path exists for `pp_to_microgrid.py`'s QUBO formulation**: [arXiv:2406.05916](https://arxiv.org/abs/2406.05916), same research lineage already cited, compact/lossless, fewer qubits.
- **Classical ML for ACOPF has a credibility problem the field just exposed itself**: [Revisiting Deep AC-OPF](https://arxiv.org/abs/2509.00655) (Aug 2025) found plain linear regression beats several published "deep learning beats classical" results by up to 54×. Hold quantum claims to the same bar.
- **HIFLD Open (a cited dataset source) shut down August 2025** — dead links if anything here ever pointed at it live. Microsoft's GridSFM dataset (continental-scale, OPF-solvable) is a strong replacement candidate.
- **PyPSA reached v1.0** (stable, native stochastic optimization) — first real alternative to pandapower for uncertainty-aware grid optimization work.
- Quantum-inspired classical solvers (Toshiba SB, GPU tensor-network emulators) are the toughest honest baseline right now — repeatedly close gaps claimed by both QA and QAOA-family algorithms, at far larger scale, no hardware queue.
